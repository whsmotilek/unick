# UNICK — статус и план

_Обновлено 7 октября 2026. Отложенные задачи — [BACKLOG.md](BACKLOG.md). Сервер — [deploy/README.md](../deploy/README.md)._

**Платформа:** https://unick.online. Бэкенд — self-hosted Supabase на VPS Beget (Санкт-Петербург, данные хранятся в РФ).

## Готово к пилоту

### Автор
- **Регистрация с модерацией**: заявка уходит администратору, кабинет открывается после одобрения.
- **Конструктор курса.** Пять типов уроков:
  - видео: YouTube, VK Видео, Rutube, Kinescope или файл;
  - текст в визуальном редакторе;
  - материалы для скачивания;
  - ДЗ со сроком;
  - тест.

  Порядок модулей и уроков меняется, курс можно открыть в предпросмотре глазами ученика.
- **Доступ к курсу**: по приглашению, свободная запись или «платный» (только пометка, оплаты пока нет). Есть режим «уроки по порядку». Курсы по приглашению видят только записанные ученики.
- **Ученики**: ссылки-приглашения с лимитом мест, добавление по email, закрытие доступа, прогресс каждого ученика.
- **Проверка ДЗ**: принять или вернуть с комментарием. Принятое ДЗ засчитывает урок.
- **Аналитика**: воронка по урокам, активность по дням, ученики в зоне риска.
- **Уведомления** в кабинете и **чат** с учениками.

### Ученик
- Вступление по ссылке: регистрация, затем сразу курс.
- Программа курса, уроки, сдача ДЗ с файлами.
- Тест: ответы проверяет сервер, правильные варианты показываются только после успешной сдачи.
- Уведомления и чат.
- Смена пароля в профиле.
- Работает на телефоне.

### Администратор (`/admin`)
- Заявки авторов, цели пилота (5 авторов, 5 курсов, 50 учеников), школы, источники записи.
- Ведение своей школы в кабинете автора.

### Безопасность и инфраструктура
- **Права на уровне БД (RLS)**: 55 автотестов. Плюс смоук-тест боевого API: 56 проверок на `api.unick.online`.
- **Сервер**:
  - SSH только по ключу;
  - `ufw` пропускает только 22, 80 и 443;
  - fail2ban ловит перебор SSH, перебор паролей на сайте и сканеры;
  - лимиты авторизации считаются по IP клиента;
  - пароль от 8 символов.
- **Веб**: HTTPS, CSP и HSTS. Studio закрыта от интернета.
- **Хранилище**: лимиты размера и типов файлов, загрузка HTML/SVG/JS запрещена.
- **Бэкапы**: каждую ночь, хранятся 14 дней.
- **CI**: проверка типов, 32 юнит-теста, RLS-тесты на PostgreSQL и 13 e2e-сценариев (десктоп и телефон). Деплой на сервер — автоматически при мерже в `main`.

## Ограничения пилота (известно)

- **Почта не подключена.** Регистрация подтверждается автоматически. Сброс пароля возможен только из профиля (для вошедших) или вручную администратором. Писем-уведомлений нет — только колокольчик в кабинете.
- **Оплаты нет.** Платный курс открывается по ссылке-приглашению после оплаты, которую автор принимает сам.
- **Видео-файл — до 50 МБ.** Большие видео — через Kinescope или VK Видео (для платного контента лучше Kinescope).
