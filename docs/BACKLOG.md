## Отложено по решению команды

| # | Задача | Комментарий |
|---|---|---|
| L1 | Реквизиты оператора ПДн (ИП/ООО, ИНН, email) | Переменные GitHub `LEGAL_OPERATOR`, `LEGAL_REQUISITES`, `CONTACT_EMAIL` → политика и условия на сайте. Без этого тексты содержат заглушку |
| L2 | Юридическая проверка политики ПДн и условий | Сейчас черновики, нужен юрист |
| S1 | Отозвать GitHub-токен, который был отправлен в чат | GitHub → Settings → Developer settings → Personal access tokens. Сейчас работа идёт через `gh auth login` |
| S2 | Закрыть доступ к Google-таблице предзаписи | «Настройки доступа» → «Доступ ограничен»; в Apps Script задать свойство `SHEET_ID` |

## Перед масштабированием пилота (после первого автора)

- **Почта (SMTP)**: подтверждение email, сброс пароля, письма-уведомления (поле `notifications.emailed_at` уже есть). Без неё: автоподтверждение регистрации, сброс пароля только через профиль или вручную.
- **Email-уведомления** о новых ДЗ автору и о проверке ДЗ ученику (по таблице `notifications`).
- **Режим последовательного курса**: опция «следующий урок открывается после *сдачи* ДЗ» (сейчас — после *принятия*).
- **История попыток ДЗ**: сейчас повторная сдача перезаписывает решение.
- **Курс в архив вместо удаления**, очистка файлов удалённых курсов в хранилище.
- **Удаление аккаунта и выгрузка своих данных** (152-ФЗ).
- **Шрифты локально** вместо Google Fonts (IP посетителей не уходит в Google; CSP строже).
- **Капча на регистрацию** при появлении спама (hCaptcha / Yandex SmartCaptcha, GoTrue поддерживает).
- **Бэкапы вне сервера** (объектное хранилище Beget/Selectel), проверка восстановления.
- **Мониторинг**: uptime-проверка сайта и API, алерт в Telegram; отчёт fail2ban.

## Продукт

- Оплата курсов (ЮKassa/Prodamus), учёт сетевых продаж и комиссии 15%.
- Публичные страницы автора (`/@slug`) и курса, каталог-сеть, учёт источника записи.
- Кураторы: приглашение из интерфейса, чат куратора.
- Потоки и группы, дедлайны потока.
- Сертификат о прохождении (PDF).
- Загрузка аватара файлом.
- Telegram-бот (уведомления, вход).
- AI-анализ курса, рекомендации, геймификация (если подтвердится спрос).

## Технический долг

- Уроки, закрытые последовательностью, технически доступны записанному ученику через API (интерфейс их закрывает).
- Предупреждения Radix «Missing Description» в диалогах.
- Метрики CRM/дашборда автора считаются по-разному в разных местах.
- `vite.config.ts` по умолчанию собирает с базой `/unick/` (для dev и e2e) — прод собирается с `VITE_BASE=/`.
